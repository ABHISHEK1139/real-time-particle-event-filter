# Complete pinned dependency lock.
#
#   pip install -r requirements-lock.txt
#
# This file pins EVERY distribution in the dependency closure, not only the
# direct requirements. The previous revision was a "lock" in name only: 30+
# transitive dependencies (Jinja2, requests, urllib3, six, ...) were left
# unpinned and floated to whatever was newest on the day of install, so the
# reproduction it advertised was not reproducible.
#
# Provenance: every pin below was produced by pip's own resolver and verified in
# a clean virtualenv with `pip install --dry-run`, so the set is mutually
# satisfiable by construction. Verified 2026-09-29, Windows / Python 3.12.10.
#
# Pins are version-only, so pip selects the correct wheel per platform
# (cp310/cp312, win_amd64/manylinux). Regenerate with:
#   pip install -r requirements.txt -r requirements-dev.txt && pip freeze
#
# The `gnn` extra (torch, torch-geometric) is pinned but commented out of the
# default install: it is needed only by src/train_gnn.py and adds ~2.5 GB of
# wheels. Every torch path in this repo degrades cleanly to CPU.
